LOCAL REVIEW FOR AI-WRITTEN CODE

Review what your agents wrote, before GitHub sees it.

An agent leaves you a worktree full of changes that aren't committed yet. GitWarren reads that worktree directly — staged, unstaged and untracked — so you read the diff on your own machine first.
