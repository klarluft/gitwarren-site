BEFORE THE COMMIT

An agent's output isn't a commit. It's a dirty worktree.

By the time work has been committed, pushed and opened as a pull request, you have already accepted its shape. GitWarren finds the worktree where the branch is checked out and folds its staged, unstaged and untracked files into one diff.

AGENTS IN THE LOOP

Your agents take part in the review, not just in the writing.

An MCP server over stdio gives Claude Code, Codex or any MCP client the same seventeen tools the app uses — read the discussion, reply in a thread, comment on a line. Ask an agent to explain its own diff, in the review, where the answer stays.

Always attributed

A machine-written comment is always marked as one, and the tool's name comes from the MCP handshake — not from whatever the model calls itself that day.

No account

One person's app, on one machine, with no notion of anybody else.

Nothing cached

Every branch, commit and diff is read from git at the moment it is shown.

One SQLite file

Delete it and GitWarren is gone. Your repositories are untouched.

Read the diff before you push it.
